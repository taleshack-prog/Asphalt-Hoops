# 🏀 Asphalt Hoops

App de agendamento de partidas de basquete com mapa, chat realtime e convites virais.

## Início Rápido
```bash
# Terminal 1: cd infra && docker compose up -d
# Terminal 2: cd backend && npm install && npm run dev
# Terminal 3: cd mobile && npm install && npx expo install @react-native-async-storage/async-storage @react-navigation/bottom-tabs && npx expo start
```
Copie `backend/.env.example` → `backend/.env` e edite o JWT_SECRET.
